Implenment agent-sub-agent.js

It is used to spawn and maintain small llm agent other than main agent.

Main agent can seperate small work like to download paper, write a small python code, analyze paper to sub agent.

When initialzing a sub-agent, the input will be a system prompt generated by main agent and first message.

The main agent can send follow-up messages to sub-agent if needed. 

If the main agent feel no longer need sub-agent anymore, it can delete it.

All the initialization, deletion and maintain of sub agent is done in agent-sub-agent.js.
