# Toolbox

The root `../tool-box.js` composes mini-tools and `view-manager.js` switches panels.

This folder owns the Toolbox UI for molarity, buffer/reaction preparation, qPCR, and colony counting. Reusable molarity and bench-recipe math lives in `../../lib/molarity.js` and `../../lib/bench-calculations.js`. Sequence, oligo, protein, translation, extinction, and CRISPR calculations plus their UI adapters are owned by `../sequence-viewer/calculations/`.
