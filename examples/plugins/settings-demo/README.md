# Settings Demo

Install this folder with **Settings → Plugins → Add Plugin Folder**, then reload
Hikari. Open **Preferences** on its plugin row to edit the four field types.
The plugin shows the current values and listens for live changes. Its
**Switch export format** button demonstrates a partial `settings.set` update.

See [plugin settings](../../../docs/plugins/plugin-settings.md) for the manifest
schema, validation rules, persistence, and bridge contract. `hikari.js` is the
same host client used by the other examples.
