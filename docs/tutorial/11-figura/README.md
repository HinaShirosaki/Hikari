# Figura operating tutorial

Open [the illustrated tutorial](index.html), or read the [Markdown version](figura.md).

It covers creating figures, AI drawing preferences, canvas sizing, text and vector layers, artwork import and crop, selection, transforms, layers, grouping, alignment, clipboard actions, reusable assets, saved figures, duplication, and exports.

Practice files: [cell SVG](examples/cell-component.svg), [cell PNG](examples/cell-artwork.png), and [example exported figure](examples/finished-figure.svg). All artwork is fictional and intended for learning the interface.
