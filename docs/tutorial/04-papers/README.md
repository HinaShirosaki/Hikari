# Papers operating tutorial

Open [the illustrated tutorial](index.html), or read the [Markdown version](papers.md).

The guide covers the paper library, adding PDFs, folders, moving papers, reading and zooming, highlights, underlines, comments, searching selected text, the outline, paper details, the research brief, and asking Hikari about a paper. It uses a fictional example paper and an illustrative research brief.

The [example PDF](examples/buffer-choice-example.pdf) is a fictional teaching document you can upload to try the steps.

Maintenance and screenshot refresh instructions are in [tools/README.md](tools/README.md).
