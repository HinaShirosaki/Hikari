# Workflows operating tutorial

Open [the illustrated tutorial](index.html), or read the [Markdown version](workflows.md).

The guide covers workflow templates and processes, starting a process, following progress, recording, completing, and failing steps, notebook pages and attached files, optional branches, renaming and deleting processes, and building templates in the graph editor. It uses fictional example records.

Maintenance and screenshot refresh instructions are in [tools/README.md](tools/README.md).
