# Notebook operating tutorial

Open [the illustrated tutorial](index.html), or read the [Markdown version](notebook.md).

The guide covers projects, starting experiments from protocols, filling in fields, notes and result files, saving and renaming pages, the bench toolbox, result and molarity tables, buffer and reaction calculators, linking samples, gels, and assays, page protocol copies, planned and suggested pages, project dashboards, and PDF export and printing. It uses fictional examples and illustrative AI suggestions.

Maintenance and screenshot refresh instructions are in [tools/README.md](tools/README.md).
