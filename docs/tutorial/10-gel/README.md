# Gel operating tutorial

Open [the illustrated tutorial](index.html), or read the [Markdown version](gel.md).

It covers image import, cropping, processed previews, lane dividers and vertices, ladder labeling, shared and per-lane band windows, intensity measurements, manual peak integration, lane tables, saved gels, stacks, shared trim, exports, and portable projects.

Practice files use simulated data: [gel image](examples/simulated-gel.png), [control image](examples/simulated-control.png), and [two-gel project](examples/practice.gel-figure.json).
