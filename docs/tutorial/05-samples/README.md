# Samples operating tutorial

Open [the illustrated tutorial](index.html), or read the [Markdown version](samples.md).

The guide covers storage locations, containers and their types, folders, adding and editing samples, sample types and their fields, filling wells with copies, single tubes, CSV import and export, finding a sample from the top bar, managing locations and sample types, and using samples in notebook pages. It uses fictional example samples.

Maintenance and screenshot refresh instructions are in [tools/README.md](tools/README.md).
