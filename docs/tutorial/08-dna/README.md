# DNA operating tutorial

Open [the illustrated tutorial](index.html), or read the [Markdown version](dna.md).

It covers loading and saving sequences, reading and editing bases, annotations, ORFs, restriction sites, alignments, Vector Builder, Protein Builder, cloning design, Primer Library, and library folders.

An [example GenBank file](examples/teaching-vector.gbk) is included. It is fictional and intended for learning the interface.
