Functions and references

x is this well's value.

References — A1 one well, A1:H12 a block, H a whole row, or the name of a custom group. A reference covering more than one well must be wrapped in an aggregate.

Aggregates — MEAN, MEDIAN, MIN, MAX, SUM, SD, COUNT.

Functions — LOG10, LOG, LN, EXP, SQRT, ABS, POWER, ROUND.

Operators — + - * / ^ and parentheses.

Row ranges use a colon here (A1:C12); A-C is subtraction in a formula.

Each step is optional and applies in the order shown, to every well with a numeric result. References accept wells (A1), rows (A, A-C), columns (3, 3-5) or a custom group name.
